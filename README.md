# 선우의 낚시 타자

초등학교 2학년용 낚시 테마 브라우저 타자게임 MVP.

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173/projects/sunwoo-keyboard-game/` 접속.

## 현재 기능

- 한글/영어 물고기 이름 단어장
- 느긋하게/보통/바글바글 난이도
- 물고기들이 천천히 유영하다가 평균 30초 후 사라짐
- 제한시간 5분
- 점수 = 잡은 물고기 마릿수
- 성공 시 낚싯줄/물고기 잡기/물보라 이펙트
- 2벌식 QWERTY 한글 자모 위치 가이드
- 다음에 칠 자모와 올바른 손가락 번호 표시
- 최고 기록 저장

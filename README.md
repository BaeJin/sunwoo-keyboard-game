# 선우의 낚시 타자

초등학교 2학년용 낚시 테마 브라우저 타자게임 MVP.

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173/projects/sunwoo-keyboard-game/` 접속.

## 현재 기능

- 한글/영어 물고기 이름 단어장
- 느긋하게/보통/바글바글 난이도
- 물고기들이 사라지지 않고 천천히 계속 유영
- 새 물고기는 어항 좌/우 끝에서 바로 등장
- 물고기는 어항 안쪽 경계에서 튕기며 화면 밖으로 나가지 않음
- 제한시간 5분
- 점수 = 잡은 물고기 마릿수
- 물고기 이름 입력 후 Enter로 제출
- 성공 시 낚싯줄/물고기 잡기/물보라 이펙트
- 2벌식 QWERTY 한글 자모 위치 가이드
- 영어 모드도 알파벳 순서와 손가락 위치 가이드 지원
- 영어 모드 키보드는 영문을 크게, 한글 자모를 보조로 표시
- 영어 물고기 단어 아래 작은 한글 뜻 표시
- 다음에 칠 자모와 QWERTY 키 표시
- 왼손/오른손 4손가락 그림에서 사용할 손가락 점등
- 손가락 가이드는 기본적으로 맨 앞 물고기 기준, 물고기 클릭 시 해당 물고기로 전환
- 쌍자음/Shift 자모는 Shift + 기본키로 표시하고 반대손 Shift도 점등
- 오타 위치의 자/모음과 키를 빨간색으로 표시
- 최고 기록 저장
